# 遊戲畫面布局草稿（依線稿理解）

來源：`docs/wireframe/遊戲布局.png`

## 1. 畫面目的
- 以「桌面視角」呈現 4 人對局。
- 中央顯示公共區域（牌堆、價格牌、棄牌區、階段提示）。
- 四周顯示四位玩家資訊與互動入口（手牌、建築、狀態）。

## 2. 版面區塊（我目前理解）
1. 中央公共區
- 牌堆（Deck）
- 棄牌區（Discard）
- 價格牌（Price Card）
- 回合/職業階段提示（例如：目前職業、輪到誰）

2. 玩家區（四邊）
- 下方：自己（主操作區，手牌可點擊）
- 上方：對家
- 左側：玩家 A
- 右側：玩家 B

3. 玩家區內元素
- 手牌區（自己顯示完整，其他玩家可只顯示張數或背面）
- 建築區（可點擊查看建築功能）
- 玩家狀態 icon（總督、輪到、已結束）
- 頭像
- 基礎資訊（名稱、手牌數、建築數、貨物數）顯示在頭像附近
  > **[待決策 #6]** 「貨物數」是彙總數字，但 API_list.md 的建築狀態是按工廠分開計算，顯示粒度需確認 → `docs/todo/pending-decisions.md`
- 玩家摘要資訊（狀態摘要、職業特權提示、建築功能提醒）顯示在頭像附近
- 動作提示：進行動作中的玩家頭像顯示醒目提示；完成動作後提示消失
- 玩家資訊顯示模式可由使用者在設定中切換：
- `hover`：滑到任一玩家頭像時才顯示該玩家資訊與摘要
- `always`：所有玩家頭像旁都持續顯示資訊與摘要

4. 輔助資訊區
- 左下資訊面板：
- 遊戲指引（例如：現在輪到誰、正在執行哪個職業行動）
- 全局提示與操作說明（不限定自己）
- 底部：回合數 / 遊戲時間
- 右下角：`i` icon（用戶操作入口，點擊後展開操作面板）
- 設定選項包含：
- 玩家資訊顯示模式：`hover` / `always`
- 建築說明模式：`compact`（精簡）/ `detailed`（詳細）

> **[待決策 #7]** `sdd.md §5.5` 要求可在設定中「再次開啟 Onboarding 導覽」，此面板尚未包含此選項 → `docs/todo/pending-decisions.md`

5. 職業選擇 Modal（職業階段開始時）
- 觸發時機：輪到玩家選職業時自動彈出。
- Modal 標題：`選擇你的職業`。
- Modal 內容：
- 可選職業卡（製造商、建築師、礦工、議員、貿易商）
- 每張職業卡顯示是否已被選取
- 顯示已選玩家 icon（玩家頭像）標記該職業歸屬
- 狀態訊息（例如：`此職業已被 XXX 選取`）
- 操作按鈕：`隱藏`、`確定`
- 互動規則：
- 已被選取的職業不可確認
- 未選職業才可按 `確定`

6. 製造商選擇工廠 Modal（製造商職業行動時）
- 觸發時機：玩家進入製造商職業行動時彈出。
- Modal 標題：`製造商：選擇工廠生產貨物`。
- 固定提示文字：
- 一般玩家：`你可以生產 1 個貨物`
- 特權玩家：`你可以生產 2 個貨物`
- Modal 內容：
- 顯示該玩家可操作的工廠建築卡片
- 已有貨物的工廠不可選（或顯示不可選狀態）
- 被選取工廠要有醒目外框
- 操作按鈕：`隱藏`、`送出`
- 互動規則：
- 按下 `送出` 時跳出二次確認彈窗
- 特權玩家若只選 1 個工廠，二次確認需顯示提醒（可再選 1 個或直接送出）

7. 通用結果確認彈窗（可重用）
- 用途：顯示單一步驟的結果訊息，讓玩家確認後再關閉。
- 範例：`你選擇了礦工，獲得一張手牌`。
- 操作按鈕：`確認`。
- 二次確認規則：
- 若本次操作符合「需再次確認」條件（例如可選張數/數量未用滿），按 `送出` 後需先跳出二次確認彈窗。
- 若有其他建築功能在同時段發動且需要玩家確認，也可沿用此彈窗樣式與流程。

8. 建築師兩步驟 Modal（建築師職業行動時）
- 第 1 步 Modal：`建築師：選擇要建造的建築`
- 顯示可建築的手牌（與建造階段相同顯示方式）
- 操作按鈕：`放棄`、`確認`
- disable 規則：
- 若玩家已擁有同名城市建築，該卡顯示 disabled
- 若玩家手牌不足支付該建築費用（含特權折抵後），該卡顯示 disabled
- 第 2 步 Modal：`建築師：你必須支付 X 張手牌`
- 顯示可支付的手牌（與建造階段相同顯示方式）
- 操作按鈕：`放棄`、`確認`
- 玩家選滿應支付張數後才可確認送出

9. 通用卡片選擇器（Card Selector）
- 用途：所有需要「從多張卡中挑選」的 Modal 共用同一元件。
- 版面：
- 上方標題（Title）
- 中間卡片顯示區（預設同時顯示 4 張）
- 左右翻頁按鈕（僅在超出顯示張數時出現）
- 底部按鈕：`隱藏`、`確認/送出/放棄`（依流程替換）
- 行為：
- 卡片數量溢出時，若左側仍有卡片則顯示左箭頭；若右側仍有卡片則顯示右箭頭。
- 點擊 `隱藏` 後 Modal 收起並回到牌桌；玩家可再展開並保留目前選取狀態。
- 卡片可互動，但 disabled 卡維持可視不可選。
- 視覺狀態：
- `selected`：醒目外框
- `disabled`：灰化/降低對比
- `default`：可點擊未選取

### 12. 手牌超過上限棄牌 Modal（#15）

- 觸發時機：回合結束手牌超過上限時強制彈出，不可隱藏。
- 需棄掉數量 = 目前手牌數 − 上限，選滿才可送出。
- 使用通用卡片選擇器（§9）。

```text
┌──────────────────────────────────────────────────┐
│  手牌超過上限，請棄牌                            │
│  目前 9 張 / 上限 7 張 → 需棄掉 2 張            │
├──────────────────────────────────────────────────┤
│  選擇要棄掉的手牌（已選 0 / 2）：               │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐  ←  →            │
│  │ 卡1│ │ 卡2│ │ 卡3│ │ 卡4│  （超過4張顯示翻頁）│
│  └────┘ └────┘ └────┘ └────┘                   │
├──────────────────────────────────────────────────┤
│               [ 確認棄牌 ]（選滿才可按）         │
└──────────────────────────────────────────────────┘
```

> 注意：此 Modal 不提供「隱藏」或「放棄」按鈕，玩家必須完成棄牌才能繼續。

### 14. 斷線重連 UI（#17）

- 觸發時機：偵測到 Socket 斷線時，在遊戲桌面上方疊加半透明遮罩。
- 自動嘗試重連（顯示旋轉動畫）；提供手動重連與返回大廳兩個出口。

```text
┌──────────────────────────────────────────────────────┐
│          （遊戲桌面背景，70% 不透明黑色遮罩）        │
│                                                      │
│          ┌──────────────────────────────┐           │
│          │        🔄（旋轉動畫）         │           │
│          │                              │           │
│          │         連線中斷             │           │
│          │  正在嘗試重新連線，請稍候…   │           │
│          │                              │           │
│          │  [ 手動重連 ]  [ 返回大廳 ]  │           │
│          └──────────────────────────────┘           │
│                                                      │
└──────────────────────────────────────────────────────┘
```

> 重連成功後遮罩自動消失，遊戲繼續；返回大廳則清除本地對局 session。
