# 聖胡安詞彙表

## 遊戲規則

| 中文 | 英文 | 解釋/註解 |
| -------- | -------- | -------- |
| 回合 |  turn | 所有人都選過職業並執行該職業階段 |
| 職業階段 | role phase  | 每個職業會有該職業可行使的職權以及每個人可以做的事 |
| 職業 | profession  | 決定該回合要做什麼事 |
| 總督 | governor  | 標記這回合從誰先開始選職業 |
| 價格牌 | Price card  | 貿易商階段決定五種貨物價值的卡牌 |
| 貨物 |  goods | 由牌堆抽出，覆蓋在工廠建築上可供交易並賺取手牌 |
| 建築 |  building | 玩家支付錢以將手牌放置於桌面作為建築，每個建築將可以執行該張牌的功能 |
| 工廠建築 |  production building | 可以生產貨物的建築 |
| 城市建築 |  city building | 工廠建築以外的建築 |
| 建築分數 | score  | 每張建築被蓋出來之後，依據卡牌上方標示的分數計算 |
| 手牌 |  hand cards| 玩家持有的牌，可作為金錢使用，或是蓋成建築 |
| 錢 | cost  | 蓋建築所需的花費，售出貨物可以取得。每張手牌可以作為 1 塊錢使用 |
| 遊戲歷程 | log  | 遊戲階段發生的事情 |
| 生產貨物 | produce  | 產生貨物的行為，可將貨物置放於建築 |
| 販賣貨物 | sell  | 將貨物換成錢的行為 |
| 特權玩家 |  player with privilege | 選擇了該職業的人，可於選擇後執行該職業的特權 |
| 一般玩家 | player  | 於特權玩家之後，可以執行該職業階段可執行的業務 |
| 職業特權 | privilege  | 特權玩家於該職業階段可以執行的特權 |
| 職業行動 | profession process | 一般玩家於該職業階段可以執行的業務 |
| 抽牌 |  draw | 從牌堆抽牌 |
| 棄牌 |  discard | 將牌放置於棄牌區 |
| 牌堆 |  deck | 玩家可於此處獲取新的手牌 |
| 棄牌區 | discard deck  | 玩家必須將丟棄的手牌放置於此 |
| 貨物種類 | goods type  | 共 5 種：染料（Indigo）、糖（Sugar）、菸草（Tobacco）、咖啡（Coffee）、白銀（Silver）；出售時依物價牌獲得不同數量的手牌 |
| 手牌上限 | hand limit  | 預設 7 張；持有高塔（Tower）時提升至 12 張。超過須於回合開始前繳回 |
| 建築功能 | building ability  | 建築的特殊效果 |
| 遊戲順序 |   | 由總督開始順時針進行 |
| 獲勝 | win | 各玩家計算：建築基礎 VP + 壓牌分（小教堂／銀行／港口）+ 大建築加分（市政廳、工業協會、凱旋門、皇宮等），最後計算皇宮。總 VP 最高者獲勝；平手時手牌數 + 生產建築上的貨物數較多者獲勝 |
| 遊戲結束 | end | 有一位玩家達到 12 棟建築，當前回合結束後立即計分 |
| 階段結束 |   | 所有人都完成該職業行動 |
| 回合結束 |   | 所有人都選完職業 |
| 建築標價 |   | 蓋這張建築要支付的金額(手牌數量) |

## 職業

> 本專案中文職業名稱以下表為準。官方二版規則書另有異譯（議員→市長、製造商→工匠），不影響英文 ID 與程式實作。

| 中文 | 英文 | 共同行動 | 選取者特權 |
| -------- | -------- | -------- | -------- |
| 礦工 | Prospector | 一般玩家：無行動 | 特權玩家：從牌堆抽 1 張牌加入手牌 |
| 議員 | Councillor | 每位玩家抽 2 張選 1 張保留，其餘棄掉 | 特權玩家：抽 5 張選 1 張 |
| 貿易商 | Trader | 每位玩家可出售 1 個貨物 | 特權玩家：可額外多出售 1 個貨物 |
| 建築師 | Builder | 每位玩家可建造 1 棟建築 | 特權玩家：建造費用少付 1 張牌 |
| 製造商 | Producer | 每位玩家可生產 1 個貨物 | 特權玩家：可額外多生產 1 個貨物 |

## 工廠建築

共 5 種，每種可建造多棟；每棟各自生產一個對應貨物。

| 中文 | 英文 | 費用 | VP | 貨物種類 |
| -------- | -------- | :--: | :--: | -------- |
| 染料廠 | Indigo Plant | 1 | 1 | 染料（Indigo） |
| 糖廠 | Sugar Mill | 2 | 1 | 糖（Sugar） |
| 菸草廠 | Tobacco Storage | 3 | 2 | 菸草（Tobacco） |
| 咖啡廠 | Coffee Roaster | 4 | 2 | 咖啡（Coffee） |
| 銀礦廠 | Silver Smelter | 5 | 3 | 白銀（Silver） |

## 城市建築

每種城市建築最多建造 1 棟。費用 6 的大建築每種各 2 張，其餘各 3 張。

### 費用 1

| 中文 | 英文 | VP | 效果摘要 |
| -------- | -------- | :--: | -------- |
| 鐵匠廠 | Smithy | 1 | 建造生產建築時費用少付 1 |
| 金礦坑 | Gold Mine | 1 | 礦工階段翻牌庫頂 4 張，若費用全不同可取 1 張加入手牌 |
| 資料庫 | Archive | 1 | 議員階段：先將抽到的牌全加入手牌，再從整副手牌中選擇要棄的牌 |

### 費用 2

| 中文 | 英文 | VP | 效果摘要 |
| -------- | -------- | :--: | -------- |
| 市場攤位 | Market Stand | 1 | 商人階段賣出 2 個以上貨物時，額外抽 1 張 |
| 水井 | Well | 1 | 製造商階段生產 2 個以上貨物時，額外抽 1 張 |
| 黑市 | Black Market | 1 | 建造時最多可用 2 個貨物代替手牌支付費用 |
| 交易所 | Trading Post | 1 | 商人階段可額外多賣 1 個貨物 |
| 救濟院 | Poor House | 1 | 建造後手牌剩 0 或 1 張時，從牌庫抽 1 張 |
| 起重機 | Crane | 1 | 可覆蓋現有建築，舊建築費用可抵扣新建築費用 |

### 費用 3

| 中文 | 英文 | VP | 效果摘要 |
| -------- | -------- | :--: | -------- |
| 高塔 | Tower | 2 | 手牌上限從 7 提升至 12 |
| 輸水道 | Aqueduct | 2 | 製造商階段可額外多生產 1 個貨物 |
| 木匠廠 | Carpenter | 2 | 建造城市建築後抽 1 張牌 |
| 省政廳 | Prefecture | 2 | 議員階段可保留 2 張牌（而非 1 張） |
| 小教堂 | Chapel | 2 | 每回合可壓 1 張手牌置底，遊戲結束每張 +1 VP |
| 雕像 | Statue | 3 | 純得分建築（紀念碑，與凱旋門搭配加分） |

### 費用 4

| 中文 | 英文 | VP | 效果摘要 |
| -------- | -------- | :--: | -------- |
| 市場 | Market Hall | 2 | 商人階段每次賣出至少 1 個貨物，額外抽 1 張 |
| 石礦廠 | Quarry | 2 | 建造城市建築時費用少付 1 |
| 勝利柱 | Victory Column | 4 | 純得分建築（紀念碑） |

### 費用 5

| 中文 | 英文 | VP | 效果摘要 |
| -------- | -------- | :--: | -------- |
| 圖書館 | Library | 3 | 職業特權加倍（選職業時享雙重特權） |

### 費用 6（大建築，每種 2 張）

| 中文 | 英文 | VP | 遊戲結束加分規則 |
| -------- | -------- | :--: | -------- |
| 市政廳 | City Hall | 6 | 每棟城市建築各 +1 VP |

| 皇宮 | Palace | 6 | 其他建築 VP 總和除以 4（捨去）= 額外 VP |
| 凱旋門 | Triumphal Arch | 6 | 依紀念碑種類數：1 種→+4VP、2 種→+6VP、3 種→+8VP |
