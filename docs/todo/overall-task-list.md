# 整體任務清單

## 1. 規格與決策收斂
1. 完成 `AGENTS.md` 設定與內容確認。
2. 完成目前 UI/互動待決策項目定案。
3. 將所有已定案內容同步更新到 `docs/sdd/sdd.md`、`docs/gameFlow/gameFlow.md`、`docs/wireframe/layout-draft.md`。

## 2. 遊戲資料建置
1. 取得完整卡片列表（職業、工廠建築、城市建築、價格牌相關資料）。
2. 建立標準化 JSON 結構與欄位定義（id、名稱、費用、分數、效果、觸發時機等）。
3. 將卡片列表整理為專案內 JSON 檔案並版本化管理。
4. 補齊資料驗證規則（必要欄位、重複 id、數值範圍）。

## 3. 前端骨架與互動
1. 在 `app/app.vue` 建立粗略畫面架構（4 人桌面布局）。
2. 建立共用 Modal/Selector 元件骨架：
- 職業選擇 Modal
- 製造商工廠選擇 Modal
- 建築師兩步驟 Modal
- 通用結果確認彈窗
- 通用卡片選擇器
3. 建立左下遊戲指引區與右下 `i` icon 操作入口。

## 4. 狀態與流程
1. 建立基礎回合狀態機（職業選擇、職業行動、回合結束、終局檢查）。
2. 先實作順時鐘輪流操作版本。
3. 實作 12 棟建築終局提示與結束流程。
4. 實作貿易商延後公布結果（全員完成後一次結算）。

## 5. 儲存與設定
1. 實作 LocalStorage：玩家資料、房間資料、對局快照、事件記錄。
2. 實作 Onboarding 導覽紀錄（首次顯示、可再次開啟）。
3. 實作設定項目：
- 玩家資訊顯示模式（hover / always）
- 建築說明模式（compact / detailed）

## 6. 測試與驗收
1. 建立規則流程單元測試（職業流程、支付/生產/販賣規則）。
2. 建立資料層測試（JSON schema 檢查）。
3. 建立整合流程測試（開局 -> 一輪 -> 終局提示）。
